# copper-orbit
Enterprise design system foundation on branch `v1`.

Run `python3 -m http.server 5173` from this directory, then visit http://localhost:5173.

`index.html` is the interactive component catalog, `styles.css` contains base styles, `reference-theme.css` contains the active theme and component language, `navigation.js` builds the responsive product header, `app.js` supplies demo interactions, and `DESIGN_SYSTEM.md` documents rules and scope. All actions use sample data and are local previews.

`PROJECT_THINKING.md` is the living record of the user's product intent, confirmed decisions, provisional assumptions, and open questions. Review it before substantial product or design work and update it as the direction evolves.

The first product application is available at `/vayu/`. `VAYU_PROJECT.md` records its product-specific scope and assumptions.
